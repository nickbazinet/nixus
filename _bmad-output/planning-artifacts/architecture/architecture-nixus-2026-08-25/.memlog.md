- (direction) Coaching path selected; final deliverables are the concise architecture spine plus a human-facing architecture-cloud-bedrock.md solution design aligned in style and substance with architecture-entitlements-licensing.md.
- (decision) [ADOPTED] Nixus brokers every hosted Bedrock call server-side; no AWS credentials are vended to or stored on premium users' devices. Binds hosted AI invocation and prevents bypassing server-side quota enforcement.
- (decision) [ADOPTED] Quota is a configurable maximum request count per Cognito user per calendar month, enforced against a DynamoDB-backed counter. Binds metering and prevents incompatible token-based or global quota implementations.
- (decision) [ADOPTED] Premium capability is manually assigned in the AWS console for v1 by editing the user's DynamoDB record; no admin UI or billing automation is in scope. Binds entitlement administration and prevents coupling this feature to Keygen or LemonSqueezy.
- (decision) [ADOPTED] When signed in and premium with remaining quota, the desktop automatically prefers the Nixus-hosted Bedrock path over existing BYO AWS credentials without a user-facing provider toggle. Binds desktop provider selection.
- (constraint) The existing Cognito user pool and its stable sub claim are the sole identity authority for this API; no second identity system may be introduced.
- (constraint) Premium Bedrock capability is independent of LemonSqueezy/Keygen module licensing. architecture-entitlements-licensing.md supplies cloud-service conventions (AWS SAM, TypeScript, Node.js 22, ARM64, manual deployment, structured CloudWatch logging, near-zero idle cost), not shared entitlement state.
- (constraint) Hosted cloud infrastructure must be pay-per-use with near-zero cost at zero traffic; API Gateway HTTP API, Lambda, and DynamoDB on-demand are the preferred baseline pending current AWS capability verification.
- (constraint) Existing local-first behavior remains: cloud AI failures must not block app launch or non-AI functionality, and non-hosted AI behavior must degrade gracefully through existing AppError conventions.
- (decision) [ADOPTED] Provider selection is hosted-first with automatic BYO fallback: when a signed-in premium user has hosted quota and the gateway is available, use Nixus-hosted Bedrock; when quota is exhausted or the gateway is unavailable, use valid stored BYO Bedrock credentials if present; otherwise return a typed, user-visible quota-exhausted or hosted-service-unavailable error. Binds desktop routing and prevents cloud outages from disabling configured local AI.
- (constraint) Live code has one streaming Bedrock surface (chat via ConverseStream) and three non-streaming Bedrock surfaces (project advice, trends insight, multimodal statement import), spread across three incompatible provider abstractions. The architecture must establish one hosted/BYO routing boundary that all Bedrock-capable surfaces use.
- (constraint) Cognito tokens are machine-level keyring state owned solely by credentials.rs; AI credentials are per-dataset and deliberately independent. Hosted calls introduce a call-time dependency on a refreshed Cognito access token without merging the two credential lifecycles.
- (constraint) API Gateway HTTP API does not support Lambda response streaming and has a non-raisable 30-second integration timeout. Regional REST API supports STREAM response transfer and Cognito user-pool authorization, preserving token streaming at higher per-request cost but still zero idle cost.
- (decision) DynamoDB monthly quota periods are separate items keyed by Cognito sub plus YYYY-MM. Quota consumption uses one conditional atomic UpdateItem before Bedrock invocation; no explicit reset job and no transaction are required unless later audit requirements add a second atomic mutation.
- (version) Verified 2026-08-25: AWS Lambda nodejs22.x on ARM64 remains supported; Amazon Bedrock Converse and ConverseStream are available through AWS SDK for JavaScript v3; AWS SAM supports Cognito/API Gateway/Lambda/DynamoDB definitions.
- (version) Verified directly against current AWS docs on 2026-08-25: API Gateway REST APIs support ResponseTransferMode=STREAM for AWS_PROXY Lambda integrations through InvokeWithResponseStream, for all REST endpoint types; streaming is not supported by HTTP APIs. AWS::ApiGateway::Method.Integration exposes ResponseTransferMode STREAM|BUFFERED in CloudFormation.
- (direction) Recommended transport: one Regional API Gateway REST API, managed Cognito user-pool authorizer, and one response-streaming Lambda route for all hosted Bedrock operations. This preserves chat streaming, avoids custom JWT verification, and stays pay-per-use; split HTTP API plus public Function URL is rejected as needless auth and operational duplication.
- (direction) Recommended protocol: one versioned POST AI invocation route with an operation discriminator and NDJSON response frames. Chat forwards delta frames; buffered consumers accumulate until end. Entitlement/quota checks complete before streaming metadata/body so preflight failures retain meaningful HTTP status and BYO fallback is safe only before any hosted output byte is emitted.
- (constraint) Hosted fallback may occur only before the first hosted response byte. After streaming begins, upstream failure is surfaced in-band and must not retry through BYO, preventing duplicate AI output or duplicate actions.
- (direction) Recommended desktop paradigm: ports-and-adapters AI backend. Existing four AI surfaces depend on one AiBackend contract; Hosted and BYO Bedrock are adapters. Cognito session and per-dataset BYO keyring state remain separately owned and meet only in call-time routing.
- (decision) [ADOPTED] The cloud edge is one Regional API Gateway REST API with a managed Cognito user-pool authorizer and Lambda AWS_PROXY integrations configured with ResponseTransferMode=STREAM. HTTP API and public Function URL alternatives are rejected. Binds all hosted AI routes and preserves chat streaming without custom JWT verification.
- (decision) [ADOPTED] Quota uses reserve-then-refund semantics: atomically reserve before Bedrock invocation; refund against the same UTC period item only when failure occurs before any Bedrock response event/output. Once output begins, disconnects and upstream failures remain charged. Lambda crashes may conservatively leak one request; no reconciler in v1.
- (decision) [ADOPTED] Premium hosted Bedrock has highest provider precedence across every AI surface, including advice/trends when OpenAI is explicitly configured. When hosted quota is unavailable, fallback resumes the existing configured provider: BYO Bedrock or OpenAI where that surface supports it; Bedrock-only surfaces require BYO Bedrock or return a typed error.
- (decision) [ADOPTED] Deploy the Cognito-authorized API, Lambda, DynamoDB, and Bedrock IAM integration in us-east-1; use the existing us.anthropic.claude-sonnet-4-6 cross-region inference profile from that source region.
- (constraint) Infrastructure deployment is automated in GitHub Actions. Reuse the existing web-ci.yml pattern (aws-actions/configure-aws-credentials@v4, us-east-1), but use a separately scoped SAM deployment principal/secrets rather than granting CloudFormation/Lambda/IAM mutation rights to the web content-deploy key. PRs verify/build; default-branch pushes deploy after verification.
- (decision) [ADOPTED] Hosted AI is content-stateless: prompts, financial context, attachments, and generated responses exist only in memory for one invocation and are never written to DynamoDB or logs. Persist only quota/operational metadata (Cognito sub, UTC period, counts, operation, timestamps, latency, status, token usage); structured logs must exclude request/response bodies and file names/paths.
- (constraint) The server, not the desktop, owns the model ID, inference profile, operation allowlist, request schema, payload ceilings, and per-operation output-token ceilings. The client cannot select arbitrary models or generation limits; monthly request quota is not the sole denial-of-wallet control.
- (decision) [ADOPTED] Use one DynamoDB on-demand table with a USER#<cognito-sub> configuration item (premium, monthly_request_limit, version, timestamps) and immutable-period USAGE#<sub>#<YYYY-MM> items (reserved/completed/refunded counts plus aggregate token/operation metadata). No reset job. Enforcement performs a consistent config read followed by a transaction that rechecks config version/premium/limit and conditionally reserves the monthly usage item.
- (decision) [ADOPTED] One quota unit equals one actual Bedrock invocation. A visible chat message that triggers a local tool and then a second model turn consumes two units. Quota tracks cost-bearing model calls, not UI gestures.
- (version) Verified 2026-08-25: AWS SAM Api event supports ResponseTransferMode=RESPONSE_STREAM and maps it to API Gateway Integration ResponseTransferMode; AWS::Serverless::Api DefinitionBody/OpenAPI also supports x-amazon-apigateway-integration.responseTransferMode=STREAM.
- (decision) [ADOPTED] The desktop remains canonical owner of feature prompts, conversation assembly, local tool execution, and response parsing. The cloud gateway accepts finalized operation-tagged inference payloads, but owns auth, premium/quota enforcement, model allowlist, payload/output ceilings, Bedrock invocation, and transport framing.
- (decision) [ADOPTED] API Gateway methods require a Cognito access token carrying custom resource-server scope nixus-api/ai.invoke. The existing app client is updated to allow/request this scope; desktop login adds it to COGNITO_SCOPES; existing sessions must sign in again. Premium remains a DynamoDB capability, not an OAuth scope.
- (decision) [ADOPTED] Hosted-AI transmission is disclosed through updated Terms and Privacy Policy only; there is no in-app consent gate or provider toggle. Before rollout, public claims that data never leaves the machine must be corrected to explain transmission through Nixus and AWS Bedrock, regions/provider handling, Nixus-controlled non-retention, and BYO fallback.
- (decision) Quota authority is exact: charged_count is the sole net monthly gate and remaining=max(0, limit-charged_count). Reserve atomically adds one to charged_count and monotonic reservation_count; refund atomically subtracts one charged_count and adds one refund_count; completion/failure and token/operation metrics are monotonic observability fields only.
- (decision) Reserve, refund, and finalization transactions each use stable server-generated ClientRequestToken values for SDK retry idempotency; client_request_id remains tracing-only. UTC period and transaction tokens are computed once at request start and carried through all writes.
- (decision) ConverseStream messageStart is the exact commit event. Stream exception events before messageStart are pre-output: refund and return HTTP error. After messageStart, emit API Gateway streaming prelude/meta; no refund/fallback. End frame includes stop_reason and usage.
- (decision) HostedAiState is keyed by Cognito sub and cleared on sign-out, session-expired transition, successful login as another sub, and any subject mismatch before use. Missing API scope is detected from the access-token scope claim and yields reauthentication_required, not an infinite refresh/fallback loop.
- (decision) One closed fallback matrix governs behavior: 403 premium_required, 429 quota_exhausted, 503 hosted_unavailable, and post-refresh auth failure may fall back before commit; 400 validation and 413 payload_too_large never fall back; any post-messageStart error never falls back. Missing-scope 401 requires re-sign-in and may use configured BYO while reauthentication is pending.
- (decision) State protection is mandatory: DynamoDB stable logical ID/key schema, DeletionPolicy Retain, UpdateReplacePolicy Retain, point-in-time recovery; deployment role cannot delete/replace the table. CI uses GitHub OIDC with aws-actions/configure-aws-credentials v6, production environment protection, no new long-lived AWS key.
- (decision) Global denial-of-wallet controls share the table: GLOBAL/CONFIG enabled+monthly limit and GLOBAL/USAGE#YYYY-MM charged_count; the same reserve/refund transaction gates and updates user and global counters. Missing/disabled/exhausted global config fails hosted calls with 503. Stage throttle 10 RPS/burst 20, Lambda reserved concurrency 10, server input+output ceilings, and AWS Budget alerts are required.
- (decision) Production desktop uses stable https://api.nixusapp.com; local development disables hosted AI unless NIXUS_CLOUD_AI_API_URL is explicitly set. SAM owns Regional custom domain/certificate/DNS via parameters. One prod stack, no staging v1.
- (constraint) Nixus-controlled stores retain no AI content, but AWS Bedrock may process/retain content under its service terms and cross-region abuse-detection policies; legal disclosures must state this accurately. Existing statement-import path/file and raw-model-output logging must be removed before hosted rollout.
