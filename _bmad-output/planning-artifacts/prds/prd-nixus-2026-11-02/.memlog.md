- (decision) New top-level nav item 'Home' (above Finance, Car, AI) hosts the AI-first dashboard page; existing '/' finance dashboard is untouched and stays reachable under Finance
- (decision) UI generation approach: custom declarative JSON catalog inspired by A2UI (a2ui.org) and CopilotKit's custom-catalog pattern -- named components with prop schemas, data-binding via paths to whitelisted data sources, never embedded raw data or executable code
- (decision) v1 component catalog: Metric, LineChart, BarChart, AreaChart, PieChart/Donut, Table, plus layout primitives Card/Row/Column/Grid
- (decision) v1 whitelisted data sources: all existing finance domains already surfaced on the static dashboard -- expenses by month/category, net worth history, budget vs actual, income vs expense, account balances, assets
- (decision) v1 editing model: conversational-only (ask the AI to remove/resize/add) -- no manual drag/resize/delete controls in v1
- (decision) Validate-before-render: generated JSON schema-validated server-side before persist/render; invalid output triggers a self-healing retry turn (mirrors A2UI's generate-validate-correct loop); exhausted retries fail gracefully with a message, never a broken surface
- (decision) Persistence: dashboard JSON tree persisted per local profile in SQLite, reloaded identically on next login -- consistent with Nixus local-first single-user model, no multi-tenant concern
- (decision) Builds on existing chat/tool-call/action-confirmation architecture (ai/chat.rs, lib/chatActions.ts) rather than a new AI subsystem
